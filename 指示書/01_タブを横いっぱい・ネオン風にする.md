# 01 タブを横いっぱい・ネオン風にする

触るファイルは `src/App.jsx` だけ。`onClick` の中身（押したときの動き）は変えない。**見た目だけ**を変える。

---

## 0. ゴールの絵

```
今：
[workTime][breakTime][dashBoard][practice]                 ← 左に寄って、幅もバラバラ
 (選んでいるタブが灰色、他が色付き → 逆に見える)

完成後：
┌──────────────┬──────────────┬──────────────┬──────────────┐
│   workTime   │  breakTime   │  dashBoard   │   practice   │  ← 画面の横幅を4等分
└━━━━━━━━━━━━━━┴──────────────┴──────────────┴──────────────┘
   ↑ 選んだタブだけ、文字と下線がネオンで光る。他は暗い灰色
```

例え：**ネオン看板が4枚並んでいて、選んだ1枚だけ電気が入る**。

| 手順 | やること | 例え |
|---|---|---|
| 1 | 4つのボタンを `<nav>` で包む | 4人を1本のベンチに座らせる |
| 2 | 各ボタンに `flex-1` を付ける | ベンチを4人で同じ幅ずつ分ける |
| 3 | 見た目を作る関数 `getTabClassName` を作る | 看板の「スイッチ」 |
| 4 | 色ごとのネオンの定数を4つ用意する | 看板ごとのネオン管の色 |
| 5 | 4つのボタンの `className` を差し替える | 各看板にスイッチをつなぐ |

---

## 1. 4つのボタンを `<nav>` で包む

今は、4つのボタンが `<div className="background ...">` の中にバラバラに置かれている（`App.jsx` の 468〜510 行あたり）。
これを1つの箱 `<nav>` に入れる。

```jsx
<nav className="flex border-b border-neutral-800">
  <button ...>workTime</button>
  <button ...>breakTime</button>
  <button ...>dashBoard</button>
  <button ...>practice</button>
</nav>
```

| 書いたもの | 何をしているか |
|---|---|
| `<nav>` | 「ここはメニュー（移動するためのボタン）です」という意味の箱。`<div>` でも動くが、意味が伝わる名前の方が読みやすい |
| `flex` | 中身を**横一列**に並べる。ベンチを置くイメージ |
| `border-b border-neutral-800` | 箱の下に暗い線を1本引く。光っていないタブとの境目が分かる |

---

## 2. 各ボタンに `flex-1` を付けて4等分

```
flex だけ：       [work][break][dash][prac]               ← 中身の文字の分しか幅を取らない
flex-1 を付ける： [   work   ][  break   ][   dash   ][   prac   ]  ← 余った幅を同じだけ分け合う
```

例え：**ピザを4人で分ける**。`flex-1` は「みんな同じ大きさで分けてね」という合図。
1人だけ付け忘れると、その人だけ小さいピースになる。

| クラス | どこに付ける | 意味 |
|---|---|---|
| `flex` | 親（`<nav>`） | 子どもを横に並べる |
| `flex-1` | 子（各 `<button>`） | 余った幅を、兄弟で同じだけ分け合う |

`flex-1` は手順3の関数の中に入れるので、ボタンに直接は書かなくてよい。

---

## 3. 見た目を作る関数 `getTabClassName` を作る

4つのタブは「色」と「選ばれているか」以外は同じ見た目。同じ長いクラス名を4回書くと、直すときに4か所直す羽目になる。
だから**クラス名を作る仕事だけ**をする関数を1つ作る（1つの関数に1つの仕事）。

置き場所：`renderTimerPanel` の閉じ `};`（462 行あたり）の後、`return (` の前。

```jsx
  //4つのタブで同じ見た目を使い回すため、クラス名づくりを1か所にまとめる
  const getTabClassName = (isSelected, neonClassName) => {
    const baseClassName = "flex-1 py-3 border-b-2 font-bold cursor-pointer transition-all duration-300";
    if (!isSelected) return `${baseClassName} border-transparent text-neutral-500 hover:text-neutral-300`;
    return `${baseClassName} ${neonClassName}`;
  };
```

| 部分 | 何をしているか |
|---|---|
| `isSelected` | そのタブが選ばれているか（true / false）。**スイッチ** |
| `neonClassName` | そのタブのネオンの色（手順4で作る）。**ネオン管** |
| `baseClassName` | 全タブ共通の形。`flex-1`＝4等分、`py-3`＝上下の余白、`border-b-2`＝下線の太さ、`transition-all duration-300`＝0.3秒かけてふわっと光る |
| `if (!isSelected) return ...` | 選ばれていなければ、先に「暗い灰色」を返して終わる（だめな方を先に `return`） |
| `border-transparent` | 下線を透明にして見えなくする（線の太さは残るので、選んだときに文字がガタッと動かない） |
| `hover:text-neutral-300` | マウスを乗せると少し明るくなる。「押せるよ」の合図 |
| 最後の `return` | 選ばれていれば、共通の形 ＋ ネオン色 |

```
         isSelected
   ┌──────┴──────┐
 false            true
   │               │
 暗い灰色        ネオン色で光る
```

## 4. 色ごとのネオンの定数を用意する

`getTabClassName` のすぐ上に、4色分を書く。

```jsx
  //Tailwindはファイルに書かれた文字そのまましか見つけられないので、色ごとに全部書いておく
  const WORK_TAB_NEON = "border-red-500 text-red-500 shadow-[0_6px_10px_-4px_#ef4444] [text-shadow:0_0_6px_#ef4444,0_0_12px_#ef4444]";
  const BREAK_TAB_NEON = "border-green-500 text-green-500 shadow-[0_6px_10px_-4px_#22c55e] [text-shadow:0_0_6px_#22c55e,0_0_12px_#22c55e]";
  const DASHBOARD_TAB_NEON = "border-blue-500 text-blue-500 shadow-[0_6px_10px_-4px_#3b82f6] [text-shadow:0_0_6px_#3b82f6,0_0_12px_#3b82f6]";
  const PRACTICE_TAB_NEON = "border-yellow-500 text-yellow-500 shadow-[0_6px_10px_-4px_#eab308] [text-shadow:0_0_6px_#eab308,0_0_12px_#eab308]";
```

| クラス | 何をしているか |
|---|---|
| `border-red-500` | 下線を赤にする（ネオン管そのもの） |
| `text-red-500` | 文字を赤にする |
| `shadow-[0_6px_10px_-4px_#ef4444]` | 下線の**下に**赤い光をにじませる。数字は「横0・下に6px・ぼかし10px・広がり-4px（細く絞る）」 |
| `[text-shadow:0_0_6px_#ef4444,0_0_12px_#ef4444]` | 文字の周りに光を**2重**にかける。近くの強い光(6px)＋遠くの弱い光(12px) |

**2重の光**は、タイマーの再生ボタンなどで使っている `glowStyle`（`App.jsx` 337 行あたり）と同じ考え方。
本物のネオン管も「芯が強く光って、周りがぼんやり明るい」ので、2枚重ねるとそれっぽくなる。

```
 1枚だけ：   ░▓work▓░        ← ただの影っぽい
 2枚重ね：  ░░▒▓work▓▒░░     ← 芯＋にじみで、ネオンっぽい
```

### なぜ `text-${color}-500` のように組み立てないの？

Tailwind は、**ファイルの中に書いてある文字をそのまま探して**、必要な CSS だけを作る。

```
 書いたもの                  Tailwindの目
 "text-red-500"          →  「あ、text-red-500 がある。CSS作ろう」 ✅
 `text-${color}-500`     →  「text-${color}-500 …？そんなクラス知らない」 ❌ 光らない
```

例え：Tailwind は**文字を読めるけど計算はできない店員さん**。メモに「赤」と書けば赤を持ってきてくれるが、「color の色」と書くと何を持ってくればいいか分からない。
だから少し長くなっても、色ごとに全部書いておく。

## 5. 4つのボタンの `className` を差し替える

`onClick` はそのまま。`className={...}` の行だけを入れ替える。
条件が長いので、先に名前を付けた変数に入れておくと読みやすい。

`getTabClassName` の下（`return (` の前）に追加：

```jsx
  //タブが選ばれているか。workとbreakはタイマー画面にいるときだけ選ばれている扱い
  const isWorkTabSelected = mode === "work" && view === "timer";
  const isBreakTabSelected = mode === "break" && view === "timer";
  const isDashboardTabSelected = view === "dashBoard";
  const isPracticeTabSelected = view === "practice";
```

ボタン側の差し替え：

| ボタン | 今の `className` | 新しい `className` |
|---|---|---|
| workTime | `{mode === "work" && view === "timer" ? "bg-gray-700" : "bg-red-500"}` | `{getTabClassName(isWorkTabSelected, WORK_TAB_NEON)}` |
| breakTime | `{mode === "break" && view === "timer" ? "bg-gray-700" : "bg-green-500"}` | `{getTabClassName(isBreakTabSelected, BREAK_TAB_NEON)}` |
| dashBoard | `{view === "dashBoard" ? "bg-gray-700" : "bg-blue-500"}` | `{getTabClassName(isDashboardTabSelected, DASHBOARD_TAB_NEON)}` |
| practice | `{view === "practice" ? "bg-gray-700" : "bg-yellow-500"}` | `{getTabClassName(isPracticeTabSelected, PRACTICE_TAB_NEON)}` |

例（workTime だけ）：

```jsx
<nav className="flex border-b border-neutral-800">
  <button onClick={() => {
    // ← ここの中身は今のまま
  }}
    className={getTabClassName(isWorkTabSelected, WORK_TAB_NEON)}
  >workTime</button>

  {/* breakTime・dashBoard・practice も同じように差し替える */}
</nav>
```

選ばれたときの動きが**逆になる**ことに注意：

| | 今 | 完成後 |
|---|---|---|
| 選んでいるタブ | 灰色（消えている） | **光る** |
| 選んでいないタブ | 色付き（光っている） | 暗い灰色 |

## 6. 確認

`npm run dev` を打って、ブラウザで開く。

| チェック | 見るところ |
|---|---|
| ☐ | 4つのタブが画面の横いっぱいに、同じ幅で並んでいる |
| ☐ | 選んだタブだけ、文字と下線がネオンで光る。他は暗い灰色 |
| ☐ | 光っていないタブにマウスを乗せると少し明るくなる |
| ☐ | タブを切り替えると、0.3秒かけてふわっと光が移る |

## 7. つまずいたら

| 症状 | よくある原因 | 確かめ方 |
|---|---|---|
| 光らない・色が付かない | クラス名を `${}` で組み立てている／定数の中のスペル違い | 定数の文字を1つずつ見る。`#ef4444` の `#` 抜けもよくある |
| 幅がそろわない | `baseClassName` に `flex-1` がない／`<nav>` に `flex` がない | DevTools でボタンを選んで、`flex: 1` が付いているか見る |
| 横に並ばず縦に並ぶ | ボタンが `<nav>` の外に出ている | `<nav>` と `</nav>` の間に4つとも入っているか |
| 選んだときに文字がガタッと動く | 選んでいないときの `border-transparent` を消してしまった | 下線の太さは常に残し、色だけ透明にする |
| `getTabClassName is not defined` | 関数を `return (` より後ろ、または `App` の外に書いた | `renderTimerPanel` の後・`return (` の前にあるか |
| 選んでいないタブが光る | `isSelected` の true/false が逆 | `if (!isSelected)` の `!` があるか |

それでも分からなければ、画面のスクショとエラー文を持ってきてください。一緒に切り分けます。
