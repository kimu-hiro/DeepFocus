# 01 タブを横いっぱい・ネオン風にする

触るファイルは `src/App.jsx` だけ。`onClick` の中身（押したときの動き）は変えない。**見た目だけ**を変える。

---

## 0. ゴールの絵

```
今：
[workTime][breakTime][dashBoard][practice]                 ← 左に寄って、幅もバラバラ
 (選んでいるタブが灰色、他がベタ塗りの色付き)

完成後：
┌──────────────┬──────────────┬──────────────┬──────────────┐
│   workTime   │  breakTime   │  dashBoard   │   practice   │  ← 画面の横幅を4等分
└──────────────┴━━━━━━━━━━━━━━┴━━━━━━━━━━━━━━┴━━━━━━━━━━━━━━┘
   ↑ 選んだタブだけ灰色（電気が消えている）。他の3枚は文字と下線がネオンで光る
```

例え：**ネオン看板が4枚並んでいて、選んだ1枚だけ電気が消える**。
「今いる場所」は消えていて、「行ける場所」が光って呼んでいるイメージ。

| 手順 | やること | 例え |
|---|---|---|
| 1 | 4つのボタンを `<nav>` で包む | 4人を1本のベンチに座らせる |
| 2 | 各ボタンに `w-1/4` を付ける | ベンチを4つの席に区切る |
| 3 | 見た目を作る関数 `getNeonTabClassName` を作る | 看板の「スイッチ」 |
| 4 | 色ごとのネオンの定数を4つ用意する | 看板ごとのネオン管の色 |
| 5 | 4つのボタンの `className` を差し替える | 各看板にスイッチをつなぐ |

## 1. 4つのボタンを `<nav>` で包む

今は、4つのボタンが `<div className="background ...">` の中にバラバラに置かれている（`App.jsx` の 468〜510 行あたり）。
これを1つの箱 `<nav>` に入れる。

```jsx
<nav className="flex border-b border-neutral-800">
  <button ...>workTime</button>
  <button ...>breakTime</button>
  <button ...>dashBoard</button>
  <button ...>practice</button>
</nav>
```

| 書いたもの | 何をしているか |
|---|---|
| `<nav>` | 「ここはページ移動のメニューです」という意味の箱。動きは `<div>` と全く同じ（下で説明） |
| `flex` | 中身を**横一列**に並べる。ベンチを置くイメージ |
| `border-b border-neutral-800` | 箱の下に暗い線を1本引く。灰色のタブの下にも線が見えて、境目が分かる |

### `<nav>` ってなに？（意味つきタグ）

タグの名前は、変数名のように自由には付けられない。HTML には**最初から決まったタグの一覧**があり、`nav` はその中の1つ。

例え：タグは**決まったメニューから選ぶ名札**。`nav` や `header` は、中身も動きも `div` と同じ箱で、**名札だけが違う**。

| タグ | 名札の意味 | 動き |
|---|---|---|
| `div` | ただの箱（意味なし） | 箱 |
| `nav` | ページ移動のメニュー | `div` と同じ箱 |
| `header` | ページの上の部分 | `div` と同じ箱 |
| `main` | ページの主役の部分 | `div` と同じ箱 |

こういう「意味つきタグ」を **セマンティックタグ** と呼ぶ。名札が役に立つ相手は3つ：

| 相手 | 名札があると |
|---|---|
| コードを読む人 | `<nav>` を見ただけで「ここはメニューだ」と分かる |
| 画面読み上げソフト（目の不自由な人が使う） | 「メニューがあります」と教えてくれる。メニューに飛ぶこともできる |
| 検索エンジン | ページのどこがメニューかを理解できる |

```
<div>                    <nav>
 ┌────────────┐         ┌────────────┐
 │ ？？？     │         │ メニュー！ │  ← 中身も見た目も同じ。名札だけ違う
 └────────────┘         └────────────┘
```

補足：React で名前を自由に付けられるのは、**大文字で始まるタグ**だけ（例：`<Practice />`）。これは HTML のタグではなく、自分で作った部品を呼び出している。

| 書き方 | 何か | 名前 |
|---|---|---|
| `<div>` `<nav>`（小文字） | HTML のタグ | 決まった一覧から選ぶ |
| `<Practice />`（大文字） | 自分で作った部品 | 自由に付けられる |

## 2. 各ボタンに `w-1/4` を付けて4等分

`w-1/4` は Tailwind の書き方で、中身は CSS の `width: 25%;` と同じ。「幅を箱の 1/4 にする」という意味。

```
flex だけ：         [work][break][dash][prac]                          ← 文字の分しか幅を取らない
justify-between：   [work]        [break]        [dash]        [prac]   ← 広がるのは「すき間」だけ
w-1/4 を付ける：    [    work    ][   break    ][    dash    ][    prac    ] ← ボタンそのものが4等分
```

例え：**ベンチを4つの席に区切る**。`justify-between` は「4人の座る間隔を空ける」だけなので、席（ボタン）の大きさは変わらない。
今回は下線や灰色の背景をタブいっぱいに付けたいので、席そのものを 1/4 にする。

| クラス | どこに付ける | 意味 |
|---|---|---|
| `flex` | 親（`<nav>`） | 子どもを横に並べる |
| `w-1/4` | 子（各 `<button>`） | 幅を親の 1/4（`width: 25%;`）にする |

`w-1/4` は手順3の関数の中に入れるので、ボタンに直接は書かなくてよい。

## 3. 見た目を作る関数 `getNeonTabClassName` を作る

4つのタブは「色」と「選ばれているか」以外は同じ見た目。同じ長いクラス名を4回書くと、直すときに4か所直す羽目になる。
だから**クラス名を作る仕事だけ**をする関数を1つ作る（1つの関数に1つの仕事）。

置き場所：`renderTimerPanel` の閉じ `};`（462 行あたり）の後、`return (` の前。

```jsx
  //4つのタブで同じ見た目を使い回すため、クラス名づくりを1か所にまとめる
  const getNeonTabClassName = (isSelected, neonClassName) => {
    const baseClassName = "w-1/4 py-3 border-b-2 font-bold cursor-pointer transition-all duration-300";
    if (isSelected) return `${baseClassName} border-transparent bg-neutral-800 text-neutral-500`;
    return `${baseClassName} ${neonClassName}`;
  };
```

| 部分 | 何をしているか |
|---|---|
| `isSelected` | そのタブが選ばれているか（true / false）。**スイッチ** |
| `neonClassName` | そのタブのネオンの色（手順4で作る）。**ネオン管** |
| `baseClassName` | 全タブ共通の形。`w-1/4`＝幅を 1/4、`py-3`＝上下の余白、`border-b-2`＝下線の太さ、`transition-all duration-300`＝0.3秒かけてふわっと切り替わる |
| `if (isSelected) return ...` | 選ばれていたら、先に「灰色（電気オフ）」を返して終わる（特別な1枚を先に `return`） |
| `border-transparent` | 下線を透明にして見えなくする（線の太さは残るので、切り替えたときに文字がガタッと動かない） |
| `bg-neutral-800 text-neutral-500` | 背景を暗い灰色、文字を灰色にする。今の `bg-gray-700` と同じ役目 |
| 最後の `return` | 選ばれていない3枚は、共通の形 ＋ ネオン色で光る |

```
         isSelected
   ┌──────┴──────┐
 true             false
   │               │
 灰色(電気オフ)   ネオン色で光る
```

## 4. 色ごとのネオンの定数を用意する

`getNeonTabClassName` のすぐ上に、4色分を書く。

```jsx
  //Tailwindはファイルに書かれた文字そのまましか見つけられないので、色ごとに全部書いておく
  const WORK_TAB_NEON = "border-red-500 shadow-[0_6px_10px_-4px_#ef4444] [text-shadow:0_0_6px_#ef4444,0_0_12px_#ef4444]";
  const BREAK_TAB_NEON = "border-green-500 shadow-[0_6px_10px_-4px_#22c55e] [text-shadow:0_0_6px_#22c55e,0_0_12px_#22c55e]";
  const DASHBOARD_TAB_NEON = "border-blue-500 shadow-[0_6px_10px_-4px_#3b82f6] [text-shadow:0_0_6px_#3b82f6,0_0_12px_#3b82f6]";
  const PRACTICE_TAB_NEON = "border-yellow-500 shadow-[0_6px_10px_-4px_#eab308] [text-shadow:0_0_6px_#eab308,0_0_12px_#eab308]";
```

| クラス | 何をしているか |
|---|---|
| `border-red-500` | 下線を赤にする（ネオン管そのもの） |
| `shadow-[0_6px_10px_-4px_#ef4444]` | 下線の**下に**赤い光をにじませる。数字は「横0・下に6px・ぼかし10px・広がり-4px（細く絞る）」 |
| `[text-shadow:0_0_6px_#ef4444,0_0_12px_#ef4444]` | 文字の周りに光を**2重**にかける。近くの強い光(6px)＋遠くの弱い光(12px) |

### 文字の色を書かないのはなぜ？（白は親から受け継ぐ）

文字は**白**にする。色付きの文字より、白い文字の周りが色で光る方がネオン管らしく見えるため。

でも定数に `text-white` は書かない。一番外側の `<div>`（`return (` のすぐ下）に、もう `text-white` が付いているから。
文字の色は**親から子へ受け継がれる**ので、タブが自分で色を決めなければ、親と同じ白になる。

例え：親が「家族はみんな白い制服」と決めている。子（タブ）が自分の服を指定しなければ、親と同じ白を着る。

```
<div className="... text-white">   ← 親：ここで白に決めている
  <nav>
    <button>workTime</button>      ← 子：何も書かなければ白を受け継ぐ
```

注意：`text-white-500` のように番号を付けると、Tailwind にないクラスになって**無視される**（白には 500 などの濃さの番号がない）。

**2重の光**は、タイマーの再生ボタンなどで使っている `glowStyle`（`App.jsx` 337 行あたり）と同じ考え方。
本物のネオン管も「芯が強く光って、周りがぼんやり明るい」ので、2枚重ねるとそれっぽくなる。

```
 1枚だけ：   ░▓work▓░        ← ただの影っぽい
 2枚重ね：  ░░▒▓work▓▒░░     ← 芯＋にじみで、ネオンっぽい
```

### なぜ `border-${color}-500` のように組み立てないの？

Tailwind は、**ファイルの中に書いてある文字をそのまま探して**、必要な CSS だけを作る。

```
 書いたもの                  Tailwindの目
 "border-red-500"        →  「あ、border-red-500 がある。CSS作ろう」 ✅
 `border-${color}-500`   →  「border-${color}-500 …？そんなクラス知らない」 ❌ 光らない
```

例え：Tailwind は**文字を読めるけど計算はできない店員さん**。メモに「赤」と書けば赤を持ってきてくれるが、「color の色」と書くと何を持ってくればいいか分からない。
だから少し長くなっても、色ごとに全部書いておく。

## 5. 4つのボタンの `className` を差し替える

`onClick` はそのまま。`className={...}` の行だけを入れ替える。
条件が長いので、先に名前を付けた変数に入れておくと読みやすい。

`getNeonTabClassName` の下（`return (` の前）に追加：

```jsx
  //タブが選ばれているか。workとbreakはタイマー画面にいるときだけ選ばれている扱い
  const isWorkTabSelected = mode === "work" && view === "timer";
  const isBreakTabSelected = mode === "break" && view === "timer";
  const isDashboardTabSelected = view === "dashBoard";
  const isPracticeTabSelected = view === "practice";
```

ボタン側の差し替え：

| ボタン | 今の `className` | 新しい `className` |
|---|---|---|
| workTime | `{mode === "work" && view === "timer" ? "bg-gray-700" : "bg-red-500"}` | `{getNeonTabClassName(isWorkTabSelected, WORK_TAB_NEON)}` |
| breakTime | `{mode === "break" && view === "timer" ? "bg-gray-700" : "bg-green-500"}` | `{getNeonTabClassName(isBreakTabSelected, BREAK_TAB_NEON)}` |
| dashBoard | `{view === "dashBoard" ? "bg-gray-700" : "bg-blue-500"}` | `{getNeonTabClassName(isDashboardTabSelected, DASHBOARD_TAB_NEON)}` |
| practice | `{view === "practice" ? "bg-gray-700" : "bg-yellow-500"}` | `{getNeonTabClassName(isPracticeTabSelected, PRACTICE_TAB_NEON)}` |

例（workTime だけ）：

```jsx
<nav className="flex border-b border-neutral-800">
  <button onClick={() => {
    // ← ここの中身は今のまま
  }}
    className={getNeonTabClassName(isWorkTabSelected, WORK_TAB_NEON)}
  >workTime</button>

  {/* breakTime・dashBoard・practice も同じように差し替える */}
</nav>
```

「選んだら灰色」という動きは今と同じ。変わるのは色の付け方だけ：

| | 今 | 完成後 |
|---|---|---|
| 選んでいるタブ | 灰色 | 灰色（電気オフ） |
| 選んでいないタブ | ベタ塗りの背景色 | 文字と下線が**ネオンで光る** |

## 7. つまずいたら

| 症状 | よくある原因 | 確かめ方 |
|---|---|---|
| 光らない・色が付かない | クラス名を `${}` で組み立てている／定数の中のスペル違い | 定数の文字を1つずつ見る。`#ef4444` の `#` 抜けもよくある |
| 幅がそろわない | `baseClassName` に `w-1/4` がない／`<nav>` に `flex` がない | DevTools でボタンを選んで、`width: 25%` が付いているか見る |
| 横に並ばず縦に並ぶ | ボタンが `<nav>` の外に出ている | `<nav>` と `</nav>` の間に4つとも入っているか |
| 選んだときに文字がガタッと動く | 選んでいないときの `border-transparent` を消してしまった | 下線の太さは常に残し、色だけ透明にする |
| `getNeonTabClassName is not defined` | 関数を `return (` より後ろ、または `App` の外に書いた | `renderTimerPanel` の後・`return (` の前にあるか |
| 選んだタブが光って、他が灰色になる | `isSelected` の true/false が逆 | `if (isSelected)` に余計な `!` が付いていないか |

それでも分からなければ、画面のスクショとエラー文を持ってきてください。一緒に切り分けます。
