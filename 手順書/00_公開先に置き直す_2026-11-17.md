# 00 公開先に置き直す（2026-11-17 版）

ブラウンノイズを軽くした版（2分・約1MB の m4a）を、
公開先に送るためのコマンド集。
くわしい説明は 02 の 2〜5 にある。ここはコピー用。

---

## 1. Mac の `dist/` に移動する

DeepFocus のフォルダにいるとき。

```bash
cd dist
```

ちがう場所にいるときは、家から全部書く。

```bash
cd ~/development/DeepFocus/dist
```

---

## 2. サーバーにつなぐ

パスワードを聞かれるので入れる。

```bash
sftp juwepi@85.131.246.41
```

`juwepi` の所は、前回使ったユーザー名にする。
`sftp>` と出たらつながった。ここから先は sftp の中で打つ。

---

## 3. DeepFocus のフォルダに移る

```
cd public_html/DeepFocus
```

```
ls
```

`index.html` と `assets` が見えれば、場所は合っている。

---

## 4. 新しいファイルを送る

1行ずつ打つ。

```
put index.html
```

```
put assets/index-CSzI9Oi7.js assets/
```

```
put assets/index-DlEXso4C.css assets/
```

```
put assets/brownNoise-BS_OnyxF.m4a assets/
```

| 送るもの | 中身 |
|---|---|
| `index.html` | 新しい js と音の名前が書いてある目次 |
| `index-CSzI9Oi7.js` | 部品分け＋くり返し再生が入った版 |
| `index-DlEXso4C.css` | 見た目（前と同じだけど念のため） |
| `brownNoise-BS_OnyxF.m4a` | 新しい音（約1MB） |

`put` は「Mac からサーバーへ送る」。
形は `put 送るファイル 送り先`。

---

## 5. 古いファイルを消す

```
rm assets/brownNoise-Bsm6aseu.mp3
```

```
rm assets/index-BqcFFMec.js
```

```
ls assets
```

`rm` は remove（取りのぞく）。サーバーのファイルを消す。
`.mp3` が `beepSound-CM6pFz0s.mp3` の1つだけになっていれば OK。

```
exit
```

`exit` で sftp を抜ける。

---
