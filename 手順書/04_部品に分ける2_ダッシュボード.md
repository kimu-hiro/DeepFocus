# 04 部品に分ける② ダッシュボード

ダッシュボード画面を `Dashboard.jsx` に分ける。
部品と props の考え方は、03 の「1」「2」を見る。

**見た目と動きは1つも変えない。**

---

## 0. ゴールの絵

```
App（親）
│
│ records（記録の一覧）を渡す
▼
Dashboard（子）
  ├ 総学習時間・総休憩時間を計算する
  └ 一覧を画面に出す
```

渡すものは `records` の**1つだけ**。合計の計算は、ダッシュボードでしか使っていないので、子の中に一緒に引っ越す。

例え：**家計簿のノート（records）だけ渡して、計算と清書は子に任せる**。

---

## 1. `Dashboard.jsx` を作る

`src/components/Dashboard.jsx` を作る。

```jsx
//ダッシュボード画面。
//記録(records)を受け取って、合計と一覧を出す
function Dashboard(props) {
  //Appから移したコードを書き換えずに使えるように、
  //同じ名前にしておく
  const records = props.records;

  //ここに App.jsx から切り取った「集計」を貼る（1-1）

  return (
    //ここに App.jsx から切り取った <div> を貼る（1-2）
  );
}

export default Dashboard
```

### なぜ `const records = props.records;` と書くの？

これから貼るコードには、`records` が何回も出てくる。全部を `props.records` に書き換えるのは大変で、書き漏れも起きやすい。
最初に `records` という名前で受け取っておけば、**貼ったコードをそのまま使える**。

```
props.records
   │ 最初に1回だけ取り出す
   ▼
records
   │ 貼ったコードは今まで通り records を使う
   ▼
.filter(...) / .reduce(...) / .map(...)
```

### 1-1. 集計を切り取って貼る

`App.jsx` で `//総学習時間・総休憩時間の集計` を探す。
そのコメントから `totalRestTime` の `.reduce(...)` の行までを**切り取って**、「1-1」の場所に貼る。

```
//総学習時間・総休憩時間の集計 ...   ← ここから
const totalStudyTime = records
  .filter(...)
  .reduce(...);
const totalRestTime = records
  .filter(...)
  .reduce(...);                        ← ここまで
```

### 1-2. 画面を切り取って貼る

`App.jsx` で `view === "dashBoard" &&` を探す。
その後ろの `<div className="p-6">` から、対になる `</div>` までを**切り取って**、「1-2」の場所に貼る。

```
view === "dashBoard" && <div className="p-6">  ← ここから
  <h2 ...>ダッシュボード</h2>
  ...
</div>                                          ← ここまで
```

貼ったものは**書き換えなくていい**（`records` の名前をそろえたから）。

---

## 2. App で使う

### 2-1. 取り寄せる

`App.jsx` の一番上に足す。

```jsx
import Dashboard from './components/Dashboard.jsx'
```

### 2-2. 切り取った場所に置く

切り取った後に残った `{ view === "dashBoard" && }` の部分（前後の `{` `}` も含めて）を、この1行に置き換える。

```jsx
{view === "dashBoard" && <Dashboard records={records} />}
```

| 渡すもの | 中身 |
|---|---|
| `records` | 記録の一覧（`localStorage` から読んだもの） |

## 3. 確認

`npm run dev` を打って、ダッシュボードを開く。

| チェック | 見るところ |
|---|---|
| ☐ | 総学習時間・総休憩時間が、分ける前と同じ数字 |
| ☐ | 記録の一覧が、新しい順に並んでいる |
| ☐ | タイマーを1回終わらせると、ダッシュボードの記録が増える |

## 4. つまずいたら

| 症状 | よくある原因 | 確かめ方 |
|---|---|---|
| `records is not defined` | `const records = props.records;` を書き忘れた | Dashboard の一番上を見る |
| `totalStudyTime is not defined`（App で） | App にまだ `totalStudyTime` を使っている所が残っている | App で `totalStudyTime` を検索する |
| 合計が `0時間0分0秒` | App で `records={records}` を渡し忘れた | `<Dashboard` の行を見る |
| `return (` の後ろでエラー | 貼った `<div>` の閉じタグが足りない | `<div>` と `</div>` の数を数える |
