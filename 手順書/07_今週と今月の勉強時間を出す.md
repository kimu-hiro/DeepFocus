# 07 今週と今月の勉強時間を出す

触るファイルは `src/components/Dashboard.jsx` だけ。部品分け（03〜06）が終わってから進める。
ダッシュボードの「総学習時間」の下に、「今週」と「今月」の合計を足す。
週は**月曜〜日曜**で区切る。

---

## 0. ゴールの絵

```
学習時間
総学習時間 : 12時間30分0秒
今週の学習時間 : 3時間10分0秒   ← 足す
今月の学習時間 : 8時間5分0秒    ← 足す

2026/10/23 : 25分0秒
2026/10/22 : 25分0秒
...
```

### どうやって数えるの？

記録（`records`）は、こんな形で `localStorage` に入っている。

```
[
  { recordDate: "2026/10/1",  studyTime: 1500 },
  { recordDate: "2026/10/20", studyTime: 1500 },
  { recordDate: "2026/10/20", restTime: 300 },
  { recordDate: "2026/10/23", studyTime: 1500 }
]
```

例え：**レシートの束から、今週の分だけ抜き出して足す**。

```
レシートの束（records）
   │
   │ ① 日付を見て「今週の分」だけ抜き出す
   ▼
今週のレシート
   │
   │ ② 勉強時間（studyTime）だけを足す
   ▼
今週の合計（秒）
   │
   │ ③「〇時間〇分〇秒」の文字にする
   ▼
画面に出す
```

| 手順 | 作るもの | 仕事 |
|---|---|---|
| 1 | `parseRecordDate` | 日付の文字を、計算できる日付に戻す |
| 2 | `getThisWeekMonday` | 今週の月曜を求める |
| 3 | `isInThisWeek` `isInThisMonth` | 今週か・今月かを答える |
| 4 | `sumStudyTime` | 勉強時間を足す |
| 5 | `formatHourMinSec` | 秒を「〇時間〇分〇秒」にする |
| 6 | 画面に出す | |

1つの関数に1つの仕事。

関数1〜5は、`Dashboard.jsx` の `function Dashboard(props) {` の**上**（外）に書く。どれも props を使わない「いつも同じ道具」だから（05 の「道具棚」と同じ考え方）。

```
Dashboard.jsx
│
├ 関数1〜5（道具棚）← 外に書く
│
└ function Dashboard(props) {
    合計の計算（手順4の後半）← 中に書く
    画面（手順6）
  }
```

## 1. 日付の文字を、計算できる日付に戻す

記録の `recordDate` は `"2026/10/23"` という**ただの文字**。文字のままでは「今週かどうか」を比べられない。
だから JavaScript の日付（`Date`）に戻す。

例え：「2026/10/23」と書かれた**メモ**を、**カレンダーの1マス**に置き直す。カレンダーに置けば、「何曜日？」「どっちが前？」が分かる。

```jsx
//記録の日付は "2026/10/23" という文字なので、
//計算できるように日付(Date)に戻す
const parseRecordDate = (recordDateText) => {
  const dateParts = recordDateText.split("/");
  const year = Number(dateParts[0]);
  const month = Number(dateParts[1]);
  const day = Number(dateParts[2]);
  //Dateの月は0始まり(1月=0)なので1引く
  return new Date(year, month - 1, day);
};
```

| 部分 | 何をしているか |
|---|---|
| `split("/")` | `"2026/10/23"` を `/` で切って、`["2026", "10", "23"]` にする |
| `Number(...)` | 文字の `"10"` を数の `10` にする |
| `month - 1` | `Date` は**1月を0**と数えるので、1引く（10月なら 9） |
| `new Date(年, 月, 日)` | その日の0時0分の日付を作る |

`split` は、タイマーの時間入力（`TimerPanel.jsx`）の `inputValue.split(":")` と同じ使い方。

## 2. 今週の月曜を求める

「今週」＝「今週の月曜0時から後」。なので、まず今週の月曜を求める。

```jsx
//今週の月曜0時を返す。週は月曜〜日曜で区切る
const getThisWeekMonday = () => {
  const today = new Date();
  //getDay()は 日曜=0、月曜=1 … 土曜=6
  const dayOfWeek = today.getDay();
  //日曜は週の最後なので、月曜から6日たっている
  const daysSinceMonday =
    dayOfWeek === 0 ? 6 : dayOfWeek - 1;
  return new Date(
    today.getFullYear(),
    today.getMonth(),
    today.getDate() - daysSinceMonday
  );
};
```

| 部分 | 何をしているか |
|---|---|
| `getDay()` | 曜日を数で返す（日曜=0 〜 土曜=6） |
| `daysSinceMonday` | 月曜から何日たったか |
| `getDate() - daysSinceMonday` | 今日の日にちから、その日数を戻す |

`getDay()` の数と、月曜からの日数：

| 曜日 | `getDay()` | 月曜から何日？ |
|---|---|---|
| 月 | 1 | 0 |
| 火 | 2 | 1 |
| 金 | 5 | 4 |
| 土 | 6 | 5 |
| 日 | **0** | **6**（だから特別扱い） |

日曜だけ `0` なので、そのまま `- 1` すると `-1` になってしまう。だから日曜のときだけ `6` にしている。

### 月をまたいでも大丈夫？

例：10月2日（金）なら、`2 - 4 = -2` 日。マイナスの日なんてないけど、`Date` は**自動で前の月に繰り下げてくれる**。

```
new Date(2026, 9, -2)
   ↓ 10月の「-2日」→ 9月にさかのぼる
2026年9月28日（月）
```

例え：カレンダーを指で**さかのぼって数える**のと同じ。月の境目をまたいでも、そのまま数えればいい。

## 3. 今週か・今月かを答える

```jsx
//記録の日付が、今週の月曜以降ならtrue
const isInThisWeek = (recordDateText) => {
  const recordDate = parseRecordDate(recordDateText);
  return recordDate >= getThisWeekMonday();
};

//記録の日付が、今日と同じ年・同じ月ならtrue
const isInThisMonth = (recordDateText) => {
  const recordDate = parseRecordDate(recordDateText);
  const today = new Date();
  const isSameYear =
    recordDate.getFullYear() === today.getFullYear();
  const isSameMonth =
    recordDate.getMonth() === today.getMonth();
  return isSameYear && isSameMonth;
};
```

| 部分 | 何をしているか |
|---|---|
| `recordDate >= getThisWeekMonday()` | 日付どうしは `>=` で「どっちが後か」を比べられる。月曜0時かそれより後なら今週 |
| `isSameYear` | 年が同じか |
| `isSameMonth` | 月が同じか |
| `isSameYear && isSameMonth` | 両方そろって「今月」 |

なぜ年も比べるのか：月だけだと、**去年の10月**も「今月」に入ってしまうから。

```
2025/10/5  → 月は同じ10月。でも年が違う → ✖
2026/10/5  → 年も月も同じ → ✅
```

## 4. 勉強時間を足す

今の `totalStudyTime` は、こう書かれている。

```jsx
const totalStudyTime = records
  .filter((record) => record.studyTime !== undefined)
  .reduce((sum, record) => sum + record.studyTime, 0);
```

「勉強時間だけを足す」仕事は、今週・今月でも同じ。だから関数にして使い回す。

```jsx
//記録の中から、勉強時間(studyTime)だけを足す
const sumStudyTime = (targetRecords) => {
  return targetRecords
    .filter((record) => record.studyTime !== undefined)
    .reduce((sum, record) => sum + record.studyTime, 0);
};
```

例え：**電卓**。渡されたレシートの束が「全部」でも「今週の分」でも、同じように足してくれる。

この関数を使って、3つの合計を出す。今の `totalStudyTime` の3行は、下の1行目に置き換える。

```jsx
const totalStudyTime = sumStudyTime(records);

const thisWeekRecords = records.filter((record) =>
  isInThisWeek(record.recordDate)
);
const thisWeekStudyTime = sumStudyTime(thisWeekRecords);

const thisMonthRecords = records.filter((record) =>
  isInThisMonth(record.recordDate)
);
const thisMonthStudyTime = sumStudyTime(thisMonthRecords);
```

| 部分 | 何をしているか |
|---|---|
| `records.filter(...)` | 今週（今月）のレシートだけを抜き出す |
| `sumStudyTime(...)` | 抜き出した分の勉強時間を足す |

この計算は `records` を使うので、`function Dashboard` の**中**、今の `totalStudyTime` があった所に書く。

`totalRestTime`（総休憩時間）は今のまま触らない。

## 5. 秒を「〇時間〇分〇秒」にする

今の画面では、この長い式を直接書いている。

```jsx
{Math.floor(totalStudyTime / 3600)}時間
{Math.floor((totalStudyTime % 3600) / 60)}分
{totalStudyTime % 60}秒
```

今週・今月でも同じ式を書くと、3回同じものが並ぶ。だから関数にまとめる。

```jsx
//秒を「〇時間〇分〇秒」の文字にする
const formatHourMinSec = (totalSeconds) => {
  const hours = Math.floor(totalSeconds / 3600);
  const minutes = Math.floor((totalSeconds % 3600) / 60);
  const seconds = totalSeconds % 60;
  return `${hours}時間${minutes}分${seconds}秒`;
};
```

| 部分 | 何をしているか |
|---|---|
| `/ 3600` | 1時間＝3600秒。何時間分あるか |
| `% 3600` | 時間で割った**余り**（1時間に届かない分） |
| `/ 60` | その余りが何分か |
| `% 60` | 分で割った余りが、残りの秒 |

例：`3725` 秒なら

```
3725 / 3600 → 1 時間（余り 125）
 125 / 60   → 2 分（余り 5）
               5 秒
→ 「1時間2分5秒」
```

名前を `formatTime` にしないのは、`TimerPanel.jsx` に同じ名前の関数（タイマーの `mm:ss` を作るもの）があるから。ファイルが違うのでぶつかりはしないが、別の物だと名前で分かるようにする。

## 6. 画面に出す

`Dashboard.jsx` の「総学習時間」の `<p>` を、こう書き換える。

```jsx
<p>総学習時間 : {formatHourMinSec(totalStudyTime)}</p>
<p>
  今週の学習時間 : {formatHourMinSec(thisWeekStudyTime)}
</p>
<p className="mb-3">

```

| 部分 | 何をしているか |
|---|---|
| `className="mb-3"` | 下に余白を空ける。今は総学習時間に付いているので、一番下の「今月」に移す |

## 7. 確認

`npm run dev` を打って、ダッシュボードを開く。

| チェック | 見るところ |
|---|---|
| ☐ | 総学習時間が、今までと同じ数字のまま |
| ☐ | 今週・今月の学習時間が出ている |
| ☐ | 今日だけ勉強したなら、3つとも同じ数字 |

### 先週・先月の記録で試す

今日の分だけだと、3つとも同じになって違いが分からない。
**ブラウザの DevTools の Console** に、テスト用の記録を足して試す。

```js
const savedRecords =
  JSON.parse(localStorage.getItem("records")) ?? [];
savedRecords.push(
  { recordDate: "2026/9/30", studyTime: 1234 },
  { recordDate: "2026/10/1", studyTime: 1234 }
);
localStorage.setItem(
  "records", JSON.stringify(savedRecords)
);
```

ページを再読み込みして、こうなれば成功（今日が 2026/10/23 のとき）。

| 記録 | 総 | 今月 | 今週 |
|---|---|---|---|
| 9/30（先月） | 入る | 入らない | 入らない |
| 10/1（今月・先週より前） | 入る | 入る | 入らない |

`1234` 秒＝20分34秒。総は 2つ分、今月は 1つ分だけ増える。

試し終わったら、テスト用の記録を消す（`1234` 秒の記録だけを取り除く）。

```js
const cleanedRecords =
  JSON.parse(localStorage.getItem("records"))
    .filter((record) => record.studyTime !== 1234);
localStorage.setItem(
  "records", JSON.stringify(cleanedRecords)
);
```

## 8. つまずいたら

| 症状 | よくある原因 | 確かめ方 |
|---|---|---|
| 今週・今月が `0時間0分0秒` | 日付の形が `"2026/10/23"` ではない | Console で `localStorage.getItem("records")` を見る |
| 今月に先月の分が入る | `month - 1` を忘れた | `parseRecordDate("2026/10/1")` を Console で試し、10月になるか見る |
| 日曜だけ今週が変 | `dayOfWeek === 0 ? 6` を書き忘れた | 表の「日曜」の行を見直す |
| `NaN時間NaN分NaN秒` | `Number()` を忘れた／`split` の区切りが違う | `split("/")` の `/` を確かめる |
| `〇〇 is not defined` | 関数の名前のつづり違い／貼り忘れ | 手順1〜5の関数が `function Dashboard` の上にそろっているか |

### 日付の形の注意

`recordDate` は `new Date().toLocaleDateString()` で作っている。これは**ブラウザの言語**で形が変わる。

| ブラウザの言語 | 形 |
|---|---|
| 日本語 | `2026/10/23` |
| 英語（アメリカ） | `10/23/2026` |

日本語のブラウザで使っている間は問題ない。ほかの言語でも使うようになったら、記録の保存の仕方から見直す。
