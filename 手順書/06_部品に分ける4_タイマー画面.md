# 06 部品に分ける④ タイマー画面

タイマー画面（今の `renderTimerPanel`）を `TimerPanel.jsx` に分ける。
部品分けの最後で、一番むずかしい。03〜05 が終わってから進める。

**見た目と動きは1つも変えない。**

---

## 0. ゴールの絵

`renderTimerPanel` は、App の中の値を**25個くらい**直接使っている。
全部を props で渡すと大変なので、先に**整理してから**引っ越す。

| 整理のしかた | 例 |
|---|---|
| タイマー画面でしか使わない物は、**子に持っていく** | `isEditing`・`inputValue`・`formatTime`・円の計算 |
| App の state を変える処理は、App に**関数としてまとめて**、子は呼ぶだけ | リセット、時間の打ち直し |
| 見るだけの値は、**props で渡す** | `remainingTime`・`isRunning` など |

```
App（親）
│
│ 見るだけの値
│   mode / remainingTime / totalTime
│   isRunning / isMute / brownVolume
│
│ 呼ぶための関数（on〇〇）
│   onStart / onPause / onResetClick
│   onEditStart / onTimeSet
│   onMuteToggle / onBrownVolumeChange
▼
TimerPanel（子）
  ├ isEditing・inputValue（自分で持つ）
  ├ 円の計算（自分でする）
  └ 画面を描く
```

渡すものは13個。25個から半分くらいに減る。

| 手順 | やること |
|---|---|
| 1 | App に `handleResetClick`・`handleTimeSet` を作る |
| 2 | `TimerPanel.jsx` を作って、中身を引っ越す |
| 3 | 引っ越した中身を `props.〇〇` に書き換える |
| 4 | App で使う・使わなくなった物を消す |

---

## 1. App に関数を2つ作る

`App.jsx` の `handleTimerTabClick`（05 で作った）の**下**に書く。

### 1-1. リセットボタンの処理

今はリセットボタンの `onClick` の中に直接書いてある。これを App の関数にする。

```jsx
//リセットボタン。
//途中まで進んでいたら、記録するか確認を出す
const handleResetClick = () => {
  const elapsed = currentTotalTime - remainingTime;
  if (elapsed > 1) {
    setConfirmAction({ type: "reset" });
    return;
  }
  handleReset(mode);
};
```

| 今の書き方 | これから |
|---|---|
| `time - remainingTime` | `currentTotalTime - remainingTime`（同じ値。05 と同じ考え方） |
| `handleReset(panelMode)` | `handleReset(mode)`（`panelMode` は、いつも `mode` と同じ） |
| `if (elapsed <= 1) {...} else {...}` | 確認を出す方を先に `return`（05 と同じ形） |

### 1-2. 時間を打ち直したときの処理

今は入力欄の `onBlur` の中で、App の state（`setTime`・`setEndTime`・`timeRef`）を直接変えている。
これを App の関数にして、子は「打ち直したよ、○秒だよ」と**電話するだけ**にする。

```jsx
//タイマーの数字を打ち直したときに、設定時間を変える
const handleTimeSet = (newTotalSeconds) => {
  if (mode === "work") {
    setWorkTime(newTotalSeconds);
    workTimeRef.current = newTotalSeconds;
  } else {
    setBreakTime(newTotalSeconds);
    breakTimeRef.current = newTotalSeconds;
  }
  setEndTime(Date.now() + newTotalSeconds * 1000);
};
```

今の `setTime` と `timeRef` は、「work なら work 用、break なら break 用」を選んで入れておく変数だった。
その選び方を、そのまま `if` で書いている。

### `"../assets/..."` の `..` ってなに？

`..` は「**1つ上のフォルダ**」という意味。
`TimerPanel.jsx` は `components` の中にいるので、`assets` に行くには1つ上に戻る必要がある。

```
src/
├── App.jsx
│     "./assets/..."  ← 同じ階にある
├── assets/
└── components/
    └── TimerPanel.jsx
          "../assets/..."  ← 1つ上に戻ってから
```

例え：自分の部屋（`components`）から、廊下（`src`）に出てから、物置（`assets`）に入る。

### 2-1. `formatTime` を引っ越す

`App.jsx` で `const formatTime =` を探す。上のコメントから閉じ `};` までを切り取って、「2-1」に貼る。
App では、タイマー画面以外で使っていない。

### 2-2. 2つの state を引っ越す

`App.jsx` で次の2つを探して、上のコメントごと切り取って「2-2」に貼る。

```jsx
const [isEditing, setIsEditing] = useState(false);
const [inputValue, setInputValue] = useState("00:08");
```

この2つは、タイマーの数字を打ち直している間だけ使う。App のほかの所では使っていない。

例え：**自分の机の引き出し**。自分しか使わない物は、共有の棚（App）ではなく、自分の引き出しに入れておく。

### 2-3. `renderTimerPanel` の中身を引っ越す

`App.jsx` で `const renderTimerPanel =` を探す。

```
const renderTimerPanel = (panelMode) => {
  const isWork = panelMode === "work";  ← ここから
  ...
  return (
    <div>
      ...
    </div>
  );                                    ← ここまで
};
```

`{` の次の行から、`return (...);` の終わりまでを**切り取って**、「2-3」に貼る。
残った `const renderTimerPanel = (panelMode) => {` と `};` は消す。

続けて、App の `//円形プログレスバー用の計算` の所から、`progressRatio` の行を切り取って、`TimerPanel` の `return (` の**上**に貼る。

```
//円形プログレスバー用の計算 ...
const RING_RADIUS = 128;
  ↑ 消す（2で書いた）
const RING_CIRCUMFERENCE = ...;
  ↑ 消す（2で書いた）
const currentTotalTime = ...;
  ↑ App に残す（タブでも使う）
const progressRatio = ...;
  ↑ TimerPanel へ
```

## 3. 引っ越した中身を書き換える

貼ったコードには、もう App に無い名前が残っている。VS Code では、**赤い波線**が付いた所が「この名前は知らない」という印。波線を1つずつ消していく。

### 3-1. 消す行

| 消す行 | 理由 |
|---|---|
| `const time = isWork ? workTime : breakTime;` | リセットは App の `handleResetClick` に任せた |
| `const setTime = ...` | 打ち直しは App の `handleTimeSet` に任せた |
| `const timeRef = ...` | 同じ |

### 3-2. 書き換える所

| 今の書き方 | 書き換え後 |
|---|---|
| `panelMode === "work"` | `props.mode === "work"` |
| `remainingTime`（4か所） | `props.remainingTime` |
| `!isRunning` | `!props.isRunning` |
| `handleStart();` | `props.onStart();` |
| `handlePause();` | `props.onPause();` |
| `isMute` | `props.isMute` |
| `onClick={handleMute}` | `onClick={props.onMuteToggle}` |
| `brownVolume`（3か所） | `props.brownVolume` |
| `setBrownVolume(...)` | `props.onBrownVolumeChange(...)` |

`progressRatio` の行の `currentTotalTime`（3か所）は `props.totalTime` にする。

### 3-3. 処理ごと入れ替える所

**入力欄の `onBlur`**：App の state を変えていた3行を、電話1本にする。

```jsx
onBlur={() => {
  const [m, s] = inputValue.split(":").map(Number);
  const msTotal = (m || 0) * 60 + (s || 0)
  props.onTimeSet(msTotal);
  setIsEditing(false);
}}
```

| 消す行 | 代わり |
|---|---|
| `setTime(msTotal);` | `props.onTimeSet(msTotal);` |
| `setEndTime(Date.now() + msTotal * 1000);` | （`handleTimeSet` の中でやる） |
| `timeRef.current = msTotal;` | （`handleTimeSet` の中でやる） |

**数字をクリックしたとき**（`<span ... onClick=`）：

| 今の書き方 | 書き換え後 |
|---|---|
| `setIsRunning(false);` | `props.onEditStart();` |

**リセットボタン**：`onClick={(() => { const elapsed = ...` の中身を全部消して、これにする。

```jsx
onClick={props.onResetClick}
```

## 4. App で使う

### 4-1. 取り寄せる・いらない物を消す

`App.jsx` の一番上に足す。

```jsx
import TimerPanel from './components/TimerPanel.jsx'
```

そして、TimerPanel に引っ越した物の `import` を消す。

| 消す行 | 引っ越し先 |
|---|---|
| `import workIcon from ...` | TimerPanel |
| `import breakIcon from ...` | TimerPanel |
| `import { Play, Pause, ... } from "lucide-react"` | TimerPanel |

### 4-2. 置く

今のこの部分を、

```jsx
{mode === "work" && renderTimerPanel("work")}
{mode === "break" && renderTimerPanel("break")}
```

こう置き換える（外側の `view === "timer" && (` と `<>` `</>` も含めて）。

```jsx
{view === "timer" && (
  <TimerPanel
    mode={mode}
    remainingTime={remainingTime}
    totalTime={currentTotalTime}
    isRunning={isRunning}
    onStart={handleStart}
    onPause={handlePause}
    onResetClick={handleResetClick}
    onEditStart={() => setIsRunning(false)}
    onTimeSet={handleTimeSet}
    isMute={isMute}
    onMuteToggle={handleMute}
    brownVolume={brownVolume}
    onBrownVolumeChange={setBrownVolume}
  />
)}
```

今まで2行に分けていたのは、`"work"` か `"break"` を渡すため。`mode={mode}` で渡せば1つで済む。

| 渡すもの | 中身 | 子での使い道 |
|---|---|---|
| `mode` | `"work"` / `"break"` | 色・文字・アイコン |
| `remainingTime` | 残り秒 | 数字の表示・円 |
| `totalTime` | 今のモードの設定秒 | 円の伸び具合 |
| `isRunning` | 動いているか | ▶ か ⏸ か |
| `onStart` / `onPause` | `handleStart` / `handlePause` | ▶ ⏸ ボタン |
| `onResetClick` | `handleResetClick` | ■ ボタン |
| `onEditStart` | タイマーを止める関数 | 数字をクリックしたとき |
| `onTimeSet` | `handleTimeSet` | 数字を打ち直したとき |
| `isMute` / `onMuteToggle` | 音を消しているか / 切り替え | 🔊 ボタン |
| `brownVolume` / `onBrownVolumeChange` | 音量 / `setBrownVolume` | 音量スライダー |

## 5. 確認

`npm run dev` を打って、ブラウザで開く。

| チェック | やること |
|---|---|
| ☐ | work は赤、break は緑で、今まで通りの見た目 |
| ☐ | ▶ で動く・⏸ で止まる・円が伸びる |

| ☐ | 動かさずに ■ → すぐリセットされる |

| ☐ | 🔊 で音が消える・スライダーで音量が変わる |

最後に、`App.jsx` に**赤い波線と黄色い波線**が残っていないか見る。

## 6. つまずいたら

| 症状 | よくある原因 | 確かめ方 |
|---|---|---|
| アイコンの画像が出ない | `"./assets/..."` のまま | TimerPanel では `"../assets/..."` |
| `useState is not defined` | TimerPanel の1行目の `import { useState }` を忘れた | 一番上を見る |
| `〇〇 is not defined`（TimerPanel で） | `props.` の付け忘れ | 3-2 の表を見直す |
| `〇〇 is not defined`（App で） | App にまだ `renderTimerPanel`・`formatTime` などの名前が残っている | その名前で App を検索する |
| ボタンを押しても何も起きない | App で渡す名前と、子の `props.〇〇` の名前が違う | 4-2 の表と見比べる |
| 打ち直しても時間が変わらない | `onTimeSet={handleTimeSet}` を渡し忘れた | 4-2 を見る |
