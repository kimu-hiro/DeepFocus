# 02 デプロイする（作ったものをサーバーに上げる）

公開先：http://85.131.246.41/juwepi/DeepFocus/index.html
使うもの：ターミナルの `sftp`

---

## 0. 全体の絵

```
【自分の Mac】
  src/App.jsx など（作業部屋）
     │
     │ ① npm run build（段ボールに詰める）
     ▼
  dist/（完成品の箱）
     index.html
     assets/
     │
     │ ② sftp で送る（宅配便）
     ▼
【dキャリアのサーバー】
  DeepFocus フォルダ
     index.html
     assets/
     │
     │ ③ ブラウザで見る
     ▼
【ブラウザ】
  http://85.131.246.41/juwepi/DeepFocus/
```

例え：**引っ越し**。
- `src/` は散らかった作業部屋。そのままでは運べない
- `npm run build` は**段ボールに詰める作業**。ブラウザが読める形にまとめて、`dist/` という箱に入れる
- `sftp` は**宅配便**。`dist/` の中身をサーバーに届ける

| 手順 | やること | 例え |
|---|---|---|
| 1 | `npm run build` で `dist/` を作る | 段ボールに詰める |
| 2 | `sftp` でサーバーにつなぐ | 宅配便を呼ぶ |
| 3 | 「どこから」「どこへ」を合わせる | 送り元と届け先の住所を書く |
| 4 | ファイルを送る | 荷物を渡す |
| 5 | ブラウザで確認する | 届いたか見に行く |

---

## 1. `npm run build` で `dist/` を作る

```bash
cd ~/development/DeepFocus
npm run build
```

| コマンド | 何をしているか |
|---|---|
| `cd ~/development/DeepFocus` | DeepFocus のフォルダに移動する |
| `npm run build` | `src/` のコードをまとめて、`dist/` に完成品を作る |

最後に `✓ built in ...` と出れば成功。

```
dist/
├── index.html
└── assets/
    ├── index-BqcFFMec.js
    ├── index-DlEXso4C.css
    ├── workIcon-xxxx.png
    └── brownNoise-xxxx.mp3
```

| ファイル | 中身 |
|---|---|
| `index.html` | 入口のページ |
| `index-〇〇.js` | プログラム本体 |
| `index-〇〇.css` | 見た目 |
| `〇〇.png` | 画像 |
| `brownNoise-〇〇.mp3` | 音（93MB もある大きいファイル） |

### ファイル名の後ろの `-BqcFFMec` ってなに？

中身から作った「指紋」のようなもの。**中身が変わると名前も変わる**。

| ファイル | 今回コードを変えた？ | 名前 |
|---|---|---|
| `index-xxxx.js` | 変えた（タブ） | **新しい名前になる** |
| `index-xxxx.css` | 変えた（Tailwind のクラスが増えた） | **新しい名前になる** |
| 画像・音 | 変えていない | 前と同じ名前 |

なぜこうなっているか：ブラウザは一度読んだファイルを覚えておく（キャッシュ）。名前が同じだと「前と同じでしょ」と古いのを使ってしまう。名前を変えることで、**新しいファイルを必ず読ませる**。

## 2. `sftp` でサーバーにつなぐ

```bash
sftp <ユーザー名>@85.131.246.41
```

| 部分 | 意味 |
|---|---|
| `sftp` | ファイルを安全に送り合うための道具 |
| `<ユーザー名>` | dキャリアでもらったサーバーのユーザー名（前回使ったもの） |
| `@85.131.246.41` | サーバーの住所 |

パスワードを聞かれたら入力する（打っても画面には何も出ないが、ちゃんと入っている）。
`sftp>` と出たらつながった。ここから先は **sftp の中** で打つ。

---

## 3. 「どこから」「どこへ」を合わせる

sftp の中には、**自分の Mac 用**と**サーバー用**の2種類のコマンドがある。頭に `l`（local＝手元）が付くと Mac 側。

| やりたいこと | サーバー側 | 自分の Mac 側 |
|---|---|---|
| 今いる場所を見る | `pwd` | `lpwd` |
| 中身を見る | `ls` | `lls` |
| 移動する | `cd` | `lcd` |

例え：電話しながら、**相手の部屋**（`cd`）と**自分の部屋**（`lcd`）を両方歩き回れる。

### 3-1. 送り元：Mac の `dist/` に移動

```
lcd /Users/kimuhiro/development/DeepFocus/dist
lls
```

`index.html` と `assets` が見えれば OK。

### 3-2. 届け先：サーバーの DeepFocus フォルダに移動

```
cd public_html/DeepFocus
ls
```

`index.html` と `assets` が見えれば、届け先に着いた。

サーバーの中はこうなっている（つないだ直後は `/home/juwepi` にいる）。

```
/home/juwepi/            ← 家
├── private/             ← 非公開の物置
├── work/                ← 作業部屋
└── public_html/         ← ショーウィンドウ
    ├── index.php
    └── DeepFocus/       ← ここに送る
```

ブラウザから見えるのは **`public_html` の中だけ**。URL とはこう対応している。

```
http://85.131.246.41/juwepi/DeepFocus/
↓
/home/juwepi/public_html/DeepFocus/
```

`public_html` は**フォルダ**。後ろの `html` は名前の一部で、ファイルの種類ではない（種類を表すのは `index.html` のように `.` の後ろ）。

**ここで場所を間違えると、別の場所に置いてしまう**ので、`ls` で `index.html` と `assets` があることを必ず見る。

---

## 4. ファイルを送る

変わったのは `index.html` と、新しい名前の `.js` と `.css` だけ。画像と音（特に 93MB の音）は前と同じなので、送らなくていい。

```
put index.html
put assets/index-*.js assets/
put assets/index-*.css assets/
```

| コマンド | 何をしているか |
|---|---|
| `put index.html` | Mac の `index.html` を、サーバーの今いる場所に送る（上書き） |
| `put assets/index-*.js assets/` | Mac の `assets` の中の `index-〇〇.js` を、サーバーの `assets` に送る |
| `put assets/index-*.css assets/` | 同じく `.css` を送る |

`*` は「ここは何でもいい」という意味。`index-*.js` で、`index-BqcFFMec.js` のように名前の後ろが何であっても当てはまる。毎回変わる名前を覚えなくて済む。

```
送るもの：
  index.html        ✅
  index-新しい.js   ✅
  index-新しい.css  ✅
  画像・音          ✖ 中身も名前も前と同じ
```

`index.html` も送るのは、中に「新しい js と css の名前」が書いてあるから。古い `index.html` のままだと、古い js と css を読みに行ってしまう。

### 全部送り直したいとき

画像や音を変えたときなど、全部送りたいときはこう打つ（音が大きいので時間がかかる）。

```
put index.html
put -r assets
```

`-r` は「フォルダの中身も丸ごと」という意味。`assets` フォルダの中身を全部送る。

送り終わったら、sftp を抜ける。

```
exit
```

## 5. ブラウザで確認する

http://85.131.246.41/juwepi/DeepFocus/index.html を開く。

| チェック | 見るところ |
|---|---|
| ☐ | タブが横いっぱい・4等分になっている |
| ☐ | 選んだタブだけ灰色、他の3枚がネオンで光る |
| ☐ | タイマーが動く・音が鳴る |

古い見た目のままなら、**強制再読み込み**（`Cmd + Shift + R`）をする。ブラウザが覚えている古いページを捨てて、読み直してくれる。

## 6. つまずいたら

| 症状 | よくある原因 | 確かめ方 |
|---|---|---|
| `Permission denied` | ユーザー名かパスワードの間違い | もう一度打ち直す |
| `No such file or directory` | `lcd` や `cd` の場所が違う | `lpwd`・`pwd` と `lls`・`ls` で今いる場所を見る |
| 画面が真っ白 | `index.html` だけ送って、新しい `.js` を送り忘れた | サーバーで `ls assets` をして、`dist/assets` と同じ名前の `.js` があるか見る |
| 見た目が古いまま | ブラウザが古いページを覚えている | `Cmd + Shift + R` |
| 見た目が古いまま（強制再読み込みしても） | 違う場所に送った | sftp でもう一度つないで、`index.html` があるのが本当に DeepFocus のフォルダか見る |

### おまけ：古いファイルの片付け

送るたびに、サーバーの `assets` に古い `index-〇〇.js` が残っていく。動きには影響しないので、放っておいて大丈夫。
気になったら、`dist/assets` に**無い**名前の `index-〇〇.js`・`index-〇〇.css` を `rm` で消す（消す前に名前をよく見る）。
